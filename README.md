# كافيه غيم وسحب - Gam & Sahb Cafe

موقع ويب كامل ومتجاوب لكافيه "غيم وسحب" يقدم تجربة مميزة لعرض المشروبات والمأكولات.

## المميزات

✅ **تصميم متجاوب بالكامل** - يعمل على جميع الأجهزة (هواتف، أجهزة لوحية، حواسيب)  
✅ **أربعة أقسام رئيسية** مع ألوان مميزة لكل قسم  
✅ **15 منتج لكل قسم** - جاهز لإضافة 60 منتج كامل  
✅ **تأثيرات تفاعلية** - Hover، Lightbox، وتأثيرات حركية  
✅ **قائمة تنقل ذكية** - قابلة للطي على الهواتف  
✅ **صور عالية الجودة** - مع دعم صور احتياطية تلقائية  
✅ **سهولة التحديث** - إضافة صور ومعلومات المنتجات بسهولة  
✅ **زر العودة للأعلى** - لتسهيل التنقل  
✅ **زر WhatsApp عائم** - للتواصل السريع  
✅ **أسعار المنتجات** - عرض واضح للأسعار  

## الأقسام

### 1. المشروبات الباردة
- لون أزرق فاتح
- تأثير تكبير الصورة عند Hover
- آيس قهوة، سموثي فراولة، ليمونادة

### 2. المشروبات الساخنة
- لون بني دافئ
- أيقونات مميزة لكل مشروب
- وصف تفاعلي عند النقر
- قهوة تركية، لاتيه، شاي أخضر

### 3. الفريش والعصائر الطبيعية
- لون أخضر فاتح
- معلومات غذائية عند Hover
- عصائر طبيعية، سموثي أخضر، مشروبات الطاقة

### 4. المأكولات
- لون بيج/كريمي
- تأثير Lightbox لتكبير الصور
- ساندوتشات، حلويات، معجنات

## الملفات

- `index.html` - الصفحة الرئيسية
- `styles.css` - ملف التصميم الكامل
- `script.js` - التأثيرات التفاعلية

## كيفية الاستخدام

1. افتح ملف `index.html` في المتصفح
2. أو استضف الملفات على أي خادم ويب
3. قم بإنشاء مجلد `images` مع المجلدات الفرعية:
   - `images/cold/` - للمشروبات الباردة (15 صورة)
   - `images/hot/` - للمشروبات الساخنة (15 صورة)
   - `images/fresh/` - للفريش والعصائر (15 صورة)
   - `images/food/` - للمأكولات (15 صورة)
4. أضف صورك بأسماء: `cold-1.jpg` إلى `cold-15.jpg` (ونفس الشيء للأقسام الأخرى)
5. قم بتحديث أسماء المنتجات والأوصاف والأسعار في ملف HTML

**ملاحظة**: إذا لم تكن الصورة موجودة، سيتم استخدام صورة احتياطية تلقائياً.

## التخصيص

### تغيير الألوان
عدّل المتغيرات في بداية ملف `styles.css`:
```css
:root {
    --cold-color: #E3F2FD;
    --hot-color: #EFEBE9;
    --fresh-color: #E8F5E9;
    --food-color: #FFF8E1;
}
```

### إضافة الصور
1. ضع الصور في المجلدات المناسبة (`images/cold/`, `images/hot/`, إلخ)
2. أسماء الملفات يجب أن تكون: `cold-1.jpg`, `cold-2.jpg`, ... `cold-15.jpg`
3. الصور ستظهر تلقائياً في الموقع

### تحديث معلومات المنتجات
ابحث في ملف HTML عن:
- `<h3>اسم المنتج</h3>` - لتحديث الاسم
- `<p>وصف المنتج</p>` - لتحديث الوصف
- `<span class="product-price">XX ر.س</span>` - لتحديث السعر
- `data-description="..."` - لتحديث الوصف التفصيلي (للمشروبات الساخنة)

**راجع ملف `دليل_إضافة_الصور.md` للتفاصيل الكاملة**
